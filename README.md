# Lab_proj

This repository contains the source code for the MPI Lab project.

## Files
- `token_ring.c`: Implementation of a token ring synchronization mechanism using MPI.
- `ring_mpi.c`: MPI Ring implementation.

## How to Run
To run the token ring simulation with 3 processes:
```bash
mpiexec -n 3 ./token_ring.exe
```
